# Pagerbit

The command center for Claude Code, Codex and every coding agent on your Mac.

Pagerbit shows what your agents are doing in your MacBook's notch, in a dashboard and in your iPhone's Dynamic Island, and lets you answer them from anywhere.

- **Always visible.** Every live session in the notch: project, task, model, time, cost.
- **Answer anywhere.** Tool requests arrive with the exact command. Allow, Deny or Always from the island, a hotkey, your iPhone or Telegram.
- **Know the bill.** 5-hour and weekly limits with reset times, spend by model and project, renewal calendar for every AI plan.
- **Private by design.** No account, no cloud, no relay. Local backend on 127.0.0.1, phone link TLS-pinned to your Mac.

Works with Claude Code, Codex, Gemini CLI, Cursor, Copilot, Hermes, OpenCode, Cowork and local Ollama / LM Studio models.

## Get it

- Buy a key ($15, one time, iPhone app included): https://ercin.io/apps/pagerbit
- Install: `brew install --cask ercinio/pagerbit/pagerbit` or download the DMG from [Releases](https://github.com/ercinio/pagerbit/releases)
- macOS 15 or later. First launch: System Settings › Privacy & Security › Open Anyway.

This repository hosts the release builds and the signed auto-update feed (`appcast.xml`, Sparkle, EdDSA). The app source is closed.
